# Spectra OFX

Spectra is an OFX plugin by Look Supply for DaVinci Resolve that emulates motion-picture film stocks using manufacturer-published spectral sensitivity and density data from film stock technical white papers.

In addition to film emulation, Spectra gives you all the finishing touches you need: grain, halation, printer points, split toning, and diffusion. Everything works together to create a complete, cohesive film look from start to finish.

Under the hood, Spectra is powered by the data generated by the [Spectral Film LUT](https://github.com/JanLohse/spectral_film_lut) project by Jan Lohse. We've built on his foundation.

## Features

- **Film emulation** - uses spectral data from film stock data sheets to generate film responses and apply them to your footage
- **Film grain** — adds organic, format-specific grain texture that responds naturally to exposure and density, from 8 mm to 65 mm
- **Halation** — reproduces the characteristic red-edge glow around bright areas you see on motion-picture film scans
- **Split toning** — tint shadows and highlights independently for classic darkroom-style colour grading
- **Optical diffusion** — creates soft, dreamy bloom around highlights with a natural falloff, like vintage diffusion filters
- **Printer points** — dial in RGB colour timing just like a film printer, letting you warm up shadows or cool down highlights with precision

## Downloading and installing the package

[Download v0.9 beta (macOS)](https://github.com/look-supply/Spectra/releases/tag/v0.9-beta)

The plugin is unsigned, so macOS will block it the normal way. To install:

1. **Extract the zip** — double-click the downloaded file. You'll see `LookSupplySpectra.ofx.bundle`.
2. **Move it into place** — in Finder, press `Cmd+Shift+G`, type `/Library/OFX/Plugins/`, and hit Go. Drag `LookSupplySpectra.ofx.bundle` into that folder.
3. **Bypass Gatekeeper** — open **System Settings > Privacy & Security**. Scroll down. Next to *"LookSupplySpectra was blocked from loading"* click **Allow Anyway**.
4. If you don't see the message, open **Terminal** (from Applications/Utilities), paste this, and press Enter:
   ```
   sudo xattr -rd com.apple.quarantine /Library/OFX/Plugins/LookSupplySpectra.ofx.bundle
   ```
   You'll be asked for your password. Type it (nothing will show as you type) and press Enter.
5. Restart DaVinci Resolve. The plugin appears under **Look Supply Spectra** in the OFX effects list.

## Building from source
```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(sysctl -n hw.ncpu)
```

Requires: CMake 3.20+, macOS 11+ (Metal GPU), Xcode Command Line Tools. Internet connection on first build (fetches OpenFX SDK headers).

Output: `build/LookSupplySpectra.ofx.bundle`

## Install from source

```
sudo cmake --build build --target install_local
```

Or copy `build/LookSupplySpectra.ofx.bundle` to `/Library/OFX/Plugins/`. Restart Resolve — the plugin appears under **Look Supply Spectra** in the OFX effects list.

## References

Spectra is built on concepts and data from the following open-source projects:

- **[Spectral Film LUT](https://github.com/JanLohse/spectral_film_lut)** (Jan Lohse, MIT) — digitized film stock datasheet measurements and the spectral film pipeline that inspired this plugin's colour science.
- **[Halation DCTL](https://github.com/hotgluebanjo/halation-dctl)** (hotgluebanjo) — informed the exponential-falloff halation approach implemented in Spectra's Metal compute kernels.

Both projects were studied, rebuilt, and extended as GPU-accelerated OFX-native code rather than LUT-generation tools or DCTL scripts.

## Branding and compatibility

The plugin appears as **Look Supply Spectra** in Resolve’s **Look Supply** group. Look Supply uses distinct OFX identifiers and `LookSupply` bundle/executable filenames so it can coexist with existing LoFi FX effects. Saved-data paths remain compatible. GitHub repositories now live under [Look Supply](https://github.com/look-supply).

Keep your existing LoFi FX bundles installed. Look Supply is a separate set of effects with its own identifiers; existing footage continues to use its original LoFi FX effects. From the workspace root, run `./install-look-supply.sh` to build, test and install all six Look Supply plugins.

## 3D LUT export

This effect declares OFX LUT-generation support. Use Resolve's normal **Generate LUT** command to bake the compatible color processing together with other compatible nodes in the grade. There is no extra export mode or checkbox.

Film negative/print looks, printer lights, split toning, white-point adaptation and input/output color-space transforms are included. Grain, image blur, halation, diffusion and diagnostic overlays are omitted only for the LUT render. Normal playback and saved effect settings retain them.

Spectra/VHS automatically select their color-only render when the host sets `OfxImageEffectPropNoSpatialAwareness` to `"true"` in the OFX Render arguments. This is the OpenFX nonspatial-render contract; an older host that does not send the request cannot automatically omit those components. Local OFX-host tests verify this request and both CPU-image and Metal-image paths; a native Resolve-generated `.cube` is still needed to confirm the host integration.

Apply the exported LUT in the same input color space/gamma and node position as the grade it represents. A 3D LUT samples a finite RGB grid and cannot retain animation, image geometry, texture, alpha changes or clip metadata. Use a 65-point cube when available for finer sampling of nonlinear corrections.
